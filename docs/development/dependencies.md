# Dependencies

- [Aspire🔗‍](https://aspire.dev/get-started/what-is-aspire/) — Orchestrates the whole application fullstack (server, client, database, etc) in a single observation layer.
- [ASPNET Core Identity🔗‍](https://www.nuget.org/packages/Microsoft.AspNetCore.Identity.EntityFrameworkCore) — For authentication and authorisation functionality.
- [ASPNET Core Data Protection🔗‍](https://www.nuget.org/packages/Microsoft.AspNetCore.DataProtection.EntityFrameworkCore) — For persistent keys (prevents automatic sign out on app updates). 
- [Cloudinary🔗‍](https://www.nuget.org/packages/CloudinaryDotNet) — For storing and retrieving user avatars/profile pictures.
- [Docker🔗‍](https://docs.docker.com/get-started/get-docker/) — Required for server startup.
- Entity Framework Core — For mapping database tables to server objects.
- PostgresSQL — The internal database.
- [RAWG API🔗‍️](https://rawg.io/apidocs) — External database for getting game data.
- [NSubstitute🔗‍️](https://www.nuget.org/packages/NSubstitute) — Testing helper.
- [Scalar🔗‍️](https://www.nuget.org/packages/Scalar.AspNetCore) — For testing API references.
- [xUnit.v3🔗‍️](https://www.nuget.org/packages/xunit.v3) — For unit testing.
